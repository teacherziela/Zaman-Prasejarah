UPLOAD GITHUB:
1. Cipta repository baharu.
2. Upload index.html, style.css dan game.js ke root repository.
3. Settings > Pages > Deploy from a branch > main / root.
4. Buka URL GitHub Pages menggunakan HTTPS.
5. Benarkan akses kamera.

Nota: MediaPipe dimuatkan melalui CDN, jadi internet diperlukan ketika permainan dibuka.
Ada MOD DEMO menggunakan tetikus untuk ujian tanpa webcam.
